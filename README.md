# СПАРК · S.P.A.R.K. Conference

Готовая статическая версия сайта конференции для публикации на GitHub Pages.

## Публикация
1. Загрузите `index.html`, `styles.css`, `script.js`, `README.md` и папку `assets` в корень репозитория GitHub.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/ (root)`.

Главная страница: `index.html`.

Текущая версия включает 9 спикеров и их фотографии.
